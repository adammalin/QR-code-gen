# QR Studio releases

## 0.2.0 — November 19, 2026

- Add a shared local browser editor, eight MCP tools, and the Create QR Code skill.
- Export styled PNG and SVG files with automated byte-for-byte decode checks;
  support previews, batches, transparency and all eight content types.
- Protect live edits with revisions and a visible agent-access pause control.
- Preserve UTF-8 content and meaningful text/Wi-Fi whitespace, enforce a
  minimum four-module quiet zone, and tighten payload validation.
- Add a downloadable local agent plugin and connection instructions to the site.

The public site remains a standalone static app. Agent file exports and shared
editor access use the local companion. A decode match does not replace scanning
the final placed or printed code.
